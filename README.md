# Simplified Distributed Key-Value Store

This repository compares a monolithic key-value store with a simplified distributed implementation
for an applied distributed computing course.

- [`monolith-store`](monolith-store/PROJECT.md): the baseline in-memory `GET`/`PUT` service.
- [`distributed-store`](distributed-store/PROJECT.md): the distributed implementation, currently
  seeded with the same runnable baseline while distributed behavior is built.
